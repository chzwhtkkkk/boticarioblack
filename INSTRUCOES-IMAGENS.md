# 📸 Como Adicionar as Imagens dos Produtos

## Passo a Passo

### 1. Criar a pasta de imagens

Na raiz do projeto, crie a seguinte estrutura de pastas:
```
public/
  └── images/
      └── products/
```

### 2. Salvar as imagens com os nomes corretos

Salve cada imagem que você me enviou na pasta `public/images/products/` com os seguintes nomes:

1. **Kit Liz (rosa/dourado)** → `kit-liz.jpg`
2. **Kit Nativa SPA Ameixa (vermelho)** → `kit-nativa-ameixa.jpg`
3. **Kit Lily (branco/dourado)** → `kit-lily.jpg`
4. **Kit Her Code (preto)** → `kit-her-code.jpg`
5. **Kit Floratta Rose (rosa claro)** → `kit-floratta-rose.jpg`
6. **Kit Floratta Red (vermelho)** → `kit-floratta-red.jpg`
7. **Kit Elysée (rose gold)** → `kit-elysee.jpg`
8. **Kit Cuide-se Bem Deleite (rosa/branco)** → `kit-cuide-se-bem.jpg`
9. **Kit Coffee (branco)** → `kit-coffee.jpg`

### 3. Formato das imagens

- **Formato aceito:** JPG, PNG ou WEBP
- **Tamanho recomendado:** 800x800px (quadrado)
- **Peso máximo:** 500KB por imagem (para carregar rápido)

### 4. Como fazer

**Opção 1 - Pelo Explorador de Arquivos:**
1. Abra a pasta do projeto no explorador
2. Crie as pastas: `public` → `images` → `products`
3. Arraste as 9 imagens para dentro de `products`
4. Renomeie cada uma com o nome correto (veja lista acima)

**Opção 2 - Pelo VS Code:**
1. No VS Code, clique com botão direito na raiz do projeto
2. Selecione "New Folder" e crie `public`
3. Dentro de `public`, crie `images`
4. Dentro de `images`, crie `products`
5. Arraste as imagens para a pasta `products`
6. Renomeie cada uma

### 5. Verificar se funcionou

Depois de salvar as imagens:
1. Recarregue a página da loja (F5)
2. Os kits devem aparecer com as imagens corretas
3. Se aparecer imagem quebrada, verifique se o nome está exatamente igual
