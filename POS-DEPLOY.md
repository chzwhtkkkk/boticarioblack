## 🔗 CONFIGURAR DOMÍNIO

### Se você tem um domínio próprio:

#### Passo 1: Adicionar na Vercel
1. Dashboard → Seu projeto
2. Settings → Domains
3. Add Domain
4. Digite seu domínio (ex: `minhalojaboticario.com.br`)

#### Passo 2: Configurar DNS
No seu provedor de domínio (Registro.br, Hostinger, etc):

**Para domínio principal:**
```
Tipo: A
Nome: @
Valor: 76.76.21.21
TTL: 3600
```

**Para www:**
```
Tipo: CNAME
Nome: www
Valor: cname.vercel-dns.com
TTL: 3600
```

#### Passo 3: Aguardar
- Pode levar até 48h para propagar
- Geralmente funciona em 1-2 horas

## 🆘 SUPORTE PÓS-DEPLOY

### Se algo der errado:

1. **Site fora do ar:**
   - Vercel Dashboard → Status
   - Verificar logs de erro
   - Refazer deploy

2. **Imagens não carregam:**
   - Verificar caminhos
   - Limpar cache CDN
   - Reupload das imagens

3. **Checkout não funciona:**
   - Verificar variáveis ambiente
   - Testar em modo incógnito
   - Verificar console do navegador
