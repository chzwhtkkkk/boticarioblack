## 🚀 DEPLOY - 3 MÉTODOS

### Método 1: SUPER FÁCIL
```
1. deploy.bat (cria pasta dist)
2. Arraste "dist" em vercel.com
3. Pronto!
```

### Método 2: AUTOMÁTICO
```
1. deploy-vercel.bat
2. Login quando pedir
3. Pronto!
```

### Método 3: GITHUB (Profissional)
```
1. git add .
2. git commit -m "Black Friday"
3. git push
4. Conecte GitHub → Vercel
5. Deploy automático sempre!
```

**Guia completo em:** `DEPLOY-SIMPLES.md`
